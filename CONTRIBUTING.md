## Eligibility

Contributions are accepted **only from individuals who have been explicitly
authorized in writing by the repository Owner (nserdar)**. If you have not
received written authorization, do not submit pull requests, issues, or any
other contribution.

---

## Contribution Workflow

1. **Request access** — Contact the Owner via GitHub before starting any work.
2. **Create a branch** — Use a descriptive branch name such as `feat/short-description`
   or `fix/short-description`.
3. **Make focused changes** — Keep each pull request limited to a single topic.
4. **Write clear commit messages** — Follow conventional commit style where
   applicable (`feat:`, `fix:`, `docs:`, `chore:`, etc.).
5. **Open a pull request** — Provide a concise description of what was changed
   and why.
6. **Respond to review** — Address all review comments promptly. The Owner
   retains final approval authority.

## Confidentiality Clause

**This section is mandatory and non-negotiable for all contributors.**

Because this repository is private and contains proprietary information, every
authorized contributor must comply with the following obligations at all times —
including after their contribution has been merged or their access has been
revoked:

### What is confidential

All materials in this repository are confidential, including but not limited to:

- Source code (all languages and formats)
- Configuration files, environment variables, and infrastructure definitions
- Architecture diagrams, technical design documents, and specifications
- Screenshots, screen recordings, and UI/UX assets
- Issue content, pull request descriptions, and code review comments
- CI/CD pipeline definitions and any log output that may contain sensitive data
- Internal tooling, scripts, and automation workflows
- Any other information that is not already in the public domain through
  authorized disclosure by the Owner

### Prohibited actions

Without **explicit prior written approval** from the Owner, contributors must
**not**:

- Share, publish, or transmit any confidential material to any third party,
  whether an individual, organization, or online service
- Post code snippets, screenshots, architecture notes, or any portion of
  repository content on public forums, blog posts, social media, or any
  public-facing channel (including but not limited to GitHub Gists, Stack
  Overflow, Reddit, Twitter/X, LinkedIn, Medium, or similar platforms)
- Include confidential material in any portfolio, presentation, or job
  application without explicit written consent from the Owner
- Use confidential material for any purpose outside the scope of your
  authorized contribution to this repository
- Discuss internal implementation details, security measures, or business
  logic with unauthorized parties

### Reporting obligations

If you become aware of any unauthorized disclosure or suspected breach of
confidentiality, you must notify the Owner immediately via GitHub.
